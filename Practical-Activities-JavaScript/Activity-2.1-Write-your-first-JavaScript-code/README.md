# Objective

Create a basic JavaScript program that displays an alert message when a web page loads. You will set up your development environment, write HTML and JavaScript code, and test the functionality in a web browser.

## Instructions

1. Create a new folder for your files.
2. Create a new HTML file (with the `.html` file extension).
3. Save your HTML file to the new folder.
4. Create a pair of `<script>` tags in your HTML document.
5. Add JavaScript code to the `<script>` tags to create an `alert()` function to alert a new message when the HTML file loads in the web browser.
6. Save the HTML file to the new folder.
7. Open your HTML file in a web browser to test your code.


This mini project allows students to practice their first lines of JavaScript code by using the built-in `alert()` function.
