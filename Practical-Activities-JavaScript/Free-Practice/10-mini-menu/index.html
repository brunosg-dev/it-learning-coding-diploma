JavaScript Mini Menu Practice

Imagine someone tells you:

“I want a menu button and a navigation menu. On a small screen, the navigation should start closed. When the user clicks the menu button, the navigation should open. If the user clicks the button again, the navigation should close. The button should also keep track of whether the menu is open or closed for accessibility.”

Programming logic:

Find the navigation

Find the menu button

When the menu button is clicked:

check whether the navigation is open

if it is closed, open it

otherwise, close it

update the button accessibility state
