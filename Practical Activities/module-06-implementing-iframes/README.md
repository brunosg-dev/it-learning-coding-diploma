# Module 06 - Implementing Iframes

This practical activity focuses on using an iframe to embed external content into a webpage.

The aim of this activity is to practise how embedded content works, how to structure it properly inside an HTML page, and how to make it responsive for different screen sizes.

## What I Practised

In this activity, I practised:

- Creating a semantic HTML page structure
- Using an iframe to embed external content
- Adding accessibility attributes such as `title`
- Using `loading="lazy"` to improve page performance
- Applying iframe security attributes such as `sandbox` and `referrerpolicy`
- Creating a responsive iframe container with CSS
- Adding simple JavaScript controls to interact with the iframe
- Testing the page in the browser during development

## Files

This folder contains:

- `index.html` - the main HTML structure of the page
- `style.css` - the CSS used to style the page and make the iframe responsive
- `script.js` - the JavaScript used for the iframe controls

## Key Features

The page includes:

- A header section with the page title
- A main content area explaining the embedded content
- A responsive iframe section
- Extra information using an aside section
- A footer section
- Buttons to reload the iframe and request fullscreen mode

## What I Learned

I learned that iframes are useful when we need to display content from another source, such as maps, videos, or external pages.

I also learned that iframes need to be used carefully because they can affect security, privacy, accessibility, and page performance. For this reason, attributes like `title`, `loading`, `sandbox`, and `referrerpolicy` are important.

This activity also helped me understand how HTML, CSS, and JavaScript work together:

- HTML creates the structure
- CSS controls the design and responsiveness
- JavaScript adds interaction
