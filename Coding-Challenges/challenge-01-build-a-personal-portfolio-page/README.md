# Personal Portfolio Page

A responsive personal portfolio page built with HTML, CSS and a small JavaScript scroll reveal animation as part of my Coding Diploma CSS challenge.

## Project Overview

This project is a personal portfolio landing page created to practise semantic HTML structure, CSS styling, responsive layouts and basic JavaScript interaction.

The page includes a header, hero section, about section, skills section, projects section, contact section and footer.

## Features

- Semantic HTML structure
- Responsive header layout
- Hero section with background image and overlay
- Reusable section styling
- Skills and projects card layouts
- Responsive CSS Grid
- Contact call-to-action section
- Footer with navigation and social links
- Smooth scroll behaviour
- Scroll reveal animation using JavaScript
- Mobile responsive design

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Git and GitHub

## What I Practised

Through this challenge, I practised:

- Building a page with a clear HTML structure
- Organising CSS into sections
- Using flexbox for layout alignment
- Using CSS Grid for card layouts
- Creating reusable classes
- Styling buttons, cards and navigation links
- Working with media queries for responsive design
- Debugging a scrollbar issue caused by overflow and animation
- Adding a scroll reveal effect with Intersection Observer

## Responsive Design

The page was tested on desktop and mobile screen sizes. The layout adapts from multi-column desktop sections to stacked mobile sections for better readability and usability.
